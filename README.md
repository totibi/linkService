

# Описание

Сервис управления ссылками (Link Storage Service).
Сервис позволяет сохранять ссылки, получать их по короткому идентификатору и вести статистику обращений.

## Стэк

1. Веб-север из grpc + grpc-gateway для обработки GRPC и REST  API с автоматической генерацией openapi документации
2. swagger UI для отображения HTTP API, тестирования и документации
3. jackc/pgx/v5 для работы с базой данных postgreSQL
4. buf для генерации кода
5. goose cli для управлениями миграциями

## Подготовка

1. для генерации кода из proto подготовлена команда make proto
2. в папки .env пример файла кофигураций для копирования и переопределения
3. требуется запущенный postgreSQL версии 15+ с заранее созданной базой данных
4. перед запуском сервиса требуется применить миграции по инструкции ниже
5. ```go run .\cmd\main.go --env-file=env/local.env ``` запуск сервиса с указанием конфигурационного файла (без файла используется переменное окружение)

## Работа с миграциями

```
go install github.com/pressly/goose/v3/cmd/goose@latest
```

конфигурация
```
GOOSE_DRIVER=postgres
GOOSE_DBSTRING="user=postgres dbname=link sslmode=disable"
GOOSE_MIGRATION_DIR=./db/migrations
```

добавление новой миграции
```
goose -env ./env/.env create name sql 
```

применение миграций
```
goose -env ./env/.env up 
```

откат миграций
```
goose -env ./env/.env down
```

## Структура проекта

- 3rdproto: вспомогательные proto файлы для генерации кода
- api: proto сервиса ссылок
- bin: buf и proto плагины для генерации кода
- cmd: точка запуска сервиса
- db: миграции сервиса
- env: пример директории с конфигурацией сервиса
- generated: результаты генерации buf - pb.go файлы и api.swagger.json - openapi документация REST API
- internal: исходники сервиса
- swagger: экземляр swagger UI для отображения интерактивной документации
